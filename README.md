# Tv Switch

用手机通过 Wi-Fi 上的 ADB 管理安卓电视：连接、看状态、精简自带应用、管理应用、装应用、换桌面、传文件、遥控、小工具。全部界面简体中文，多彩卡片设计。

> 与 Tellyscope 的关系：本项目为独立原创代码，功能对标 Tellyscope 公开的功能描述，不是它的 Fork，没有复制它的源码、图标与文案。许可证：MIT。

## 电视端准备

1. 电视：设置 → 关于 → 连点版本号 7 次，开启开发者选项。
2. 开发者选项里开启“网络调试”（部分电视叫“无线调试”/“ADB 调试”）。
3. 手机与电视连同一个 Wi-Fi。
4. 打开 Tv Switch，输入电视 IP（网络调试一般端口 5555），点连接。
5. 电视弹出“允许调试？”时，核对指纹后点“允许”，并勾选“始终允许”。

注意：Android 11+ 无线调试的配对码流程（TLS 配对）在 v1 中尚未实现，请先用网络调试连接。

## 功能

- 连接：IP:端口连接、断开、指纹核对。
- 电视总览：存储、内存、电池温度、负载。
- 精简：先扫描、逐项确认、只禁用自带应用、可撤销、一键恢复本次禁用；关键包在受保护清单里，无法禁用。
- 应用管理：启用、禁用；卸载只针对第三方应用。
- 安装应用：APK 传到电视后执行安装；分包解析在后续版本补齐。
- 换桌面：先确认新桌面已装、能打开，再设为 Home；自带桌面可恢复。
- 传文件：ADB sync 推送底层已实现；文件选择器与双向进度在后续版本补齐。
- 遥控：方向键、确认、返回、Home、菜单、音量、静音、打字、重启；关屏仅 Android 13 及以下。
- 小工具：Private DNS、动画缩放、清缓存。

## 安全规则

1. 只禁用、不卸载自带应用；卸载只针对用户自己安装的应用。
2. 每次操作前先列出、逐项确认；本次禁用可一键恢复。
3. 受保护清单不可禁用，没有绕过开关。
4. 不用 root，不用漏洞，只用 ADB 允许的命令。
5. 无广告、无追踪、无账号；数据只在局域网内传输；ADB 密钥只存在手机私有目录。

## 编译

```bash
gradle :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

也可以直接用 GitHub Actions：推送到 main 后，Actions 会自动编译并在 Artifact 里提供 debug APK。

## 已知限制（v1）

- 未在真实电视上验证：ADB 连接、认证、shell、sync 均按公开协议实现，真实电视的兼容性需用户实测反馈。
- 无线调试配对码流程未实现。
- 精简清单为 v1 起步清单（约 18 项），不是 330+ 项完整清单；用户可在后续版本里自行添加包名。
- 文件选择器、分包解析、一键设 Home 入口在后续版本补齐，当前版本不提供假按钮。
